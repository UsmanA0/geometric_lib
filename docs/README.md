# Проект для вычисления геометрических величин

## Общее описание

Проект для вычисления площади и периметра квадрата, а также площади и длины окружности круга.

## Описание функций

### `circle.area(r)`

Вычисляет площадь круга.

* Принимает: `r` (`int`)
* Возвращает: `float`

Пример:

```python

print(area(5))

```


### `circle.perimeter(r)`

Вычисляет длину окружности.

* Принимает: `r` (`int`)
* Возвращает: `float`

Пример:

```python

print(perimeter(5))

```

### `square.area(a)`

Вычисляет площадь квадрата.

* Принимает: `a` (`int`)
* Возвращает: `int`

Пример:

```python

print(area(5))

```

### `square.perimeter(a)`

Вычисляет периметр квадрата.

* Принимает: `a` (`int`)

* Возвращает: `int`

Пример:

```python

print(perimeter(5))

```
